RDF Media Uploader.

A personal tool for publishing videos on my own YouTube channels.

RDF Media Uploader is a private, non-commercial application used by Riccardo Dal Ferro to upload and manage videos on the YouTube channels he owns and operates, such as Bytes & Ink and Riccardo Dal Ferro Composer.

It runs only on the owner's own computer and uses the official YouTube Data API to:

  • upload videos, subtitles and thumbnails;
  • set titles, descriptions, playlists and publishing schedules.

The application is not offered to the public and does not access any other person's account or data.
